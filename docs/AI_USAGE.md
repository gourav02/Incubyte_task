# AI Tool Usage Log

## Tool Used
- **Windsurf Cascade** (Agentic AI coding assistant)

## How AI Was Used

### Planning Phase
- Used AI to help structure the architecture and design decisions
- Generated initial planning document with trade-off analysis

### Implementation Phase
- **TDD Workflow**: AI assisted in writing failing tests first, then implementing code to make them pass
- **Code Generation**: AI helped scaffold boilerplate (Express routes, database migrations, React components)
- **Code Review**: Each generated piece was reviewed for correctness and quality

### Key Principle
AI was used as an accelerator, not a replacement for thinking. Each architectural decision was made deliberately, and AI-generated code was verified for correctness before committing.

## Prompt Strategy
- Started with high-level requirements and broke them into incremental steps
- Used TDD approach: write test → see it fail → implement → refactor
- Made incremental commits to show evolution of the codebase
